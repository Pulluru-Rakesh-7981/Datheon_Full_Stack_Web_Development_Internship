# Rakesh – Developer Portfolio

A responsive personal portfolio website showcasing my profile, technical skills, projects, resume and contact information.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Responsive website design
- About Me section
- Technical Skills section
- Featured Projects
- Resume download option
- Contact links
- Dark/Light mode
- Mobile navigation menu
- Project details popup

## Project Structure

```text
Portfolio/
├── index.html
├── style.css
├── script.js
└── resume.pdf
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Add your `resume.pdf` file to the project folder for the resume download feature.
